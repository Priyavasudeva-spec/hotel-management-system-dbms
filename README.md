# hotel-management-system-dbms
A static Hotel Management System developed to demonstrate and apply core DBMS concepts.
##  Project Overview
* This project is a **static Database Management System (DBMS)** that simulates a **Hotel Management System**.
* It demonstrates execution of **100 predefined SQL queries** on a **preloaded dataset**.
* No real database is used — all operations are handled using **JavaScript-based simulation**.

## Objectives

* Understand and implement **SQL queries**
* Simulate a real-world **hotel database system**
* Demonstrate **data retrieval and analysis**
* Build an interactive interface for **query visualization**


##  Project Type

*  Static DBMS Project
*  Preloaded Dataset
*  Query Simulation using JavaScript

##  Query System

*  Total Queries: **100**
*  Categories:

  * Customers (1–20)
  * Rooms (21–40)
  * Bookings (41–60)
  * Staff (61–80)
  * Payments (81–100)

###  SQL Concepts Covered

* SELECT
* WHERE
* GROUP BY
* ORDER BY
* JOIN
* Aggregate Functions


##  How It Works

1. Data is **generated and stored in JavaScript objects**
2. User selects a query from the sidebar
3. System:

   * Displays SQL query
   * Simulates execution delay
   * Processes logic internally
4. Results are shown in a **dynamic table**
